Puffer Party Helper v3.0.2

made by BotAaron_

  1. Extract the extension ZIP.
  2. Open chrome://extensions or edge://extensions and enable Developer mode.
  3. Choose Load unpacked and select the folder containing manifest.json.
  4. Click the extension icon, paste your Gemini or OpenAI API key and click Launch Puffer Party.

The extension runs directly in your browser. Reload existing game tabs after updating. Configure Autofill and Grind mode using the yellow game panel.
