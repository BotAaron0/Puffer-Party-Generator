PUFFER / COMPANION

One setup. Then just launch.

Install this unpacked extension in Chrome or Edge once.

  1. Open chrome://extensions in Chrome, or edge://extensions in Edge.
  2. Turn on Developer mode, then click Load unpacked.
  3. Select the extension folder beside PufferHelper.exe. Choose the folder containing manifest.json.
  4. Open PufferHelper.exe, enter your API key in API settings, then click Launch Krillion.

Use the same browser for installation and launching (your Windows default browser). The helper panel appears near the top right. Join your game normally: suggestions start once a category is visible. Keep the desktop app running.

The extension reads visible questions and played answers only on krillion.io. If detection misses the question, click Choose question on the panel, then click the question once. A changing page layout can require this fallback. AI rarity is estimated, and game acceptance is not guaranteed.

Your OpenAI key stays in the desktop app. Only question text is sent to OpenAI; API charges may apply. The extension communicates with a session-authenticated service bound to this computer only.
